# Day 3

## Structs

In a struct we group together different variables that are related to each
other. The size of the struct depends on the data types of the variables and how
they are arranged how much padding is in the struct.

We should try to optimize the size of the struct by rearranging the variables so
that there is minimum amount of padding.

## Enums

Enums let us give names to constants and we can use those names in our code. We
can also use it in switch case.

### Unions

In union there are different data types in same memeory location but at one time
only one of those data types is stored in memory.
