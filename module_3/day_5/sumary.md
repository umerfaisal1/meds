# Day 5

On day 5 I learned that there are different operating modes in a RISC-V cpu with
different level of privelliges like m mode, s mode, and u mode.

There is also error handling in risc-v using CSRs. These registers store the
cause of the error, the value of pc, the error handling address, etc.

RISC-V also has extentions that improve its functionality like adding floating
point instructions, adding compressed instructions, etc.
